# LICENSES

The licence texts this tree needs, besides the top-level `LICENSE` (the GNU GPL, version 3
only), which covers fm1-rocket-os, X0X and Felucca and the rest of the tree. See
[../LICENSING.md](../LICENSING.md) for what is under which licence and where it comes from.

| File | Licence | What it covers |
| --- | --- | --- |
| `MIT.txt` | MIT | Open303 (Robin Schmidt), in `firmware/src/dsp/bass303.c`; the Fukiai icon font (`web/fukiai.ttf`) |
| `Apache-2.0.txt` | Apache-2.0 | The JieLi AC79 SDK files read from your SDK checkout at build time (`uboot.boot`, `cfg_tool.bin`, `eq_cfg_hw.bin`); no SDK files are in this tree |
| `SIL-OFL-1.1.txt` | SIL Open Font License 1.1 | Barlow Semi Condensed (`assets/fonts/`) and Terminus (`assets/fonts/ter-u*.bdf`) |

The font-specific copies of the OFL are kept beside the fonts too
(`assets/fonts/Barlow-OFL.txt`, `assets/fonts/Terminus-LICENSE.txt`), and the Fukiai MIT text
is at `web/FUKIAI-LICENSE.txt`.
