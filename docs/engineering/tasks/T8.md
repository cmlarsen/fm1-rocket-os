## Build
1. **STUDIO 7, songs.** SAVE held opens the list.
   - Rows: a `+ New song` row, then the 5 slots, each with its name, or "empty" for an unused slot, plus a playing/current marker.
   - A storage meter shows the used slots out of 5.
   - SELECT moves through the rows; SEL opens the song under the cursor; EDIT opens the song menu; HOME goes back.
2. **STUDIO 8, new song.** Pick Empty, Starter or Copy current, set the tempo (K1) and key (K2), and SEL creates the song in the first free slot. If no slot is free, say "5 songs max: delete one" and do nothing.
   - **Starter** is a generated song (`song_templates.c`): 4 drum clips, 3 bass, 3 lead, 2 chords and 1 FX, musically sensible in the chosen key and tempo, with deterministic content and unit tests.
   - **Empty** has all clips unused and sensible role engine defaults.
3. **STUDIO 11, the song menu:** Open, Copy (to the first free slot), Rename and Delete.
4. **STUDIO 12, rename,** using T8c's `name_edit_*`.
5. **STUDIO 13, delete.** Hold SEL on Delete for 1.5 s; a ring names the song and its contents. Delete uses the store's durable delete and pushes an undo entry, so HOME+REC undoes it until the next delete. Deleting the current song opens another song, or a new Empty song if none is left.
6. **Opening a song:** stop the transport, save the current song if it's dirty (the same safety rules as autosave), load the selected one, and return to the song home.
