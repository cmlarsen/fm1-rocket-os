## Build
1. **SYSTEM 1, the cheat sheet.** Holding HOME for 400 ms or more, with no other input, shows the context's HOME combos:
   - in STUDIO: REC tap = undo, PLAY tap = redo, pad tap = launch now, pad hold = clear clip, K1–K4 touch = clear knob lane, FX tap = reset all FX;
   - in LIVE: the same, minus the editing rows.
   Releasing HOME closes it. A HOME tap stays "back", and HOME combos still work while the sheet shows.
2. **SYSTEM 2, help cards.** GLO + any button shows that button's card for the current context: what tap, hold and combos do, in 3–4 lines, matching the design.
   - Releasing closes the card.
   - Write cards for every button in STUDIO, LIVE and SONGS, from the interaction model and the actual handlers. List any gesture where the two disagree in the report; don't change behaviour.
   - Inside Classic, X0X's own 1 s help stays as it is. Outside Classic, X0X's 1 s hold-help is off, so a hold never shows X0X help.
3. **Text tables:** keep all help text in one table in `ui_help.c`, so docs and tests can check it. Add `tools/check_help.py`, which fails if a button in the interaction model's gesture tables has no card.
