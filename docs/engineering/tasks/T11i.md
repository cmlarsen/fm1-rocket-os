Integration lane. It runs in parallel with T10i, which owns `ui_live.c` and the master path in `engine.c`, and T7b, which owns `ui_studio.c`, `ui_clip.c`, `song_io` editing and the clip engine's recording hooks. Stay out of those, and ask the coordinator if you need a hook in them.

## Build
1. **One `midi_in_t`.** TRS and USB share X0X's ring. If the ring can tag the source, use two. Feed every received byte or packet with the sample counter. `midi_in_tick` runs in the main loop, in the same context as the feed.
2. **Notes** on `song.live_channel` (0 = omni) play the focused role, through the held-note table, with velocity. The focused role is the last one launched or played, or BASS by default, and the same focus LIVE's PLAY layer uses. This works in STUDIO and LIVE, not in Classic, where X0X's own MIDI handling stays.
3. **Program Change** on the live channel, when `song.pc_launch` is set, launches clip = program number (0–26) through the clip engine, quantized. Out-of-range programs are ignored.
4. **CC 120 and 123** release everything (`note_release_all` plus all-off).
5. **Clock in:**
   - when F8 ticks arrive, the clip engine follows the clock's tempo (`bpm_x10`) and Start, Stop and Continue drive the transport;
   - when the clock is lost, the transport keeps going at the last tempo and a small "EXT" indicator in the header goes away.
   A GLOBAL row sets clock source to Internal or Auto (follow when present), with Auto the default. Store it in X0X's settings. **Never change the stored settings format** without a migration; use a reserved byte if one is free.
6. **X0X's own per-part MIDI channels** keep working in Classic only.

## Tests
Host scenarios using the runner's `midi` command (extend it for clock ticks if needed):
- notes on the channel play the focused role and release, with the voices back to 0;
- omni versus a fixed channel;
- PC launch, quantized;
- out-of-range PC ignored;
- CC 123 panic;
- clock at 100 bpm drives the transport and tempo;
- clock lost keeps playing;
- Start and Stop;
- MIDI notes held across a view change still release on note-off (and the fuzz-style check).
