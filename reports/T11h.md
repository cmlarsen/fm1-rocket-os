# T11h: cheat sheet and help cards

Integration lane. The task's own files are new: `firmware/src/app/ui_help.{c,h}` (the two text
tables and the drawing), `tools/check_help.py`, `tests/scenarios/help_cards.x0x` and its goldens,
and this report. `ui.c` gets small hooks; `ui_live.c`/`ui_studio.c` get one line each (the header's
`SHIFT` layer); `host/x0x_host.c`, `Makefile` and `tests/run_tests.sh` get the test plumbing.
Nothing was flashed (`make fw` only builds on deltron.local).

## What it does

Two help systems replace X0X's "hold a button ~1 s" card outside Classic.

**SYSTEM 1, the cheat sheet** (`design/project/Sys-Shift.dc.html`). Holding HOME for 400 ms with no
other input, no keys and no encoders shows the context's HOME combinations; releasing HOME closes
it. A short HOME tap still means back, and the combos keep working while the sheet is up (the sheet
only takes the main area; the combos are unchanged):

- **STUDIO**: REC tap undo · PLAY tap redo · PAD tap launch now · PAD hold clear clip · K1–K4 touch
  clear knob lane · FX tap reset all FX (the six Sys-Shift rows);
- **LIVE**: the same minus the editing rows — REC undo · PLAY redo · PAD tap launch now · FX reset.

The header's layer text reads `SHIFT` while the sheet is up (`studio_draw_header` /
`live_draw_header`), and the footer reads `HOLDING HOME` / `TAP HOME: BACK`.

**SYSTEM 2, the help cards** (`design/project/Sys-Help.dc.html`). Holding GLO and pressing (or
holding) any other button shows that button's card for the current context; releasing GLO or the
button closes it. The card is a dialog in the main area with a button chip (`REC` is red), `in
STUDIO`/`in LIVE`/`in SONGS`, and 3–4 lines. Both orders work (GLO then the button, or the button
then GLO). In SONGS the card is drawn over the list and the view is modal while it is up.

**Classic is untouched.** `help_tick` now returns unless `ui.classic`, so outside Classic a 1 s hold
shows nothing (X0X's help no longer appears), and inside Classic the original card and its
behaviour are exactly as before (`tests/scenarios/help.x0x` passes unchanged).

## The text tables

All help text is in `firmware/src/app/ui_help.c`:

- `HELP_CARD[context][button]` — one entry for **every** button (FX, SEL/SCL, ENV, LFO, EDIT, GLO,
  HOME, SAVE, ARP, SEQ, PLAY, REC, OCT−, OCT+) in **every** context (STUDIO, LIVE, SONGS). A card is
  1…4 lines at `AF_S` (12 px); written from the interaction model and the handlers, and the report
  below lists where those disagree.
- `SHEET_STUDIO` / `SHEET_LIVE` — the cheat-sheet rows (`key, tap/hold/touch, does`).

`help_cards_fit()` (host-only, called from `ui.c`'s `help_fits()`) fails if a card is missing, empty
or wider than 224 px, or if a sheet row's columns would collide. `expect helpfits` covers it.

`tools/check_help.py` reads the button names out of the interaction model's gesture tables
(`docs/product/interaction-model.md`; the header keywords are `gesture/task/control/enter/leave/
layer/keys do/purpose/shows`, so the panel vocabulary, the modes table, the LIVE layers table and
the STUDIO tasks table are all read) and fails if any of them has no card in any declared context.
The model's "GLO + any button" row means all 14 buttons, so the tool demands a full table. It found
14 buttons, all covered (14 cards in each of the three contexts); it exits 1 if a card is removed.
It runs in `make check` and in `tests/run_tests.sh`.

## Where the model and the code disagree (behaviour unchanged)

The cards follow the interaction model; these are the places the handlers do not (yet) match it.
None of these were changed.

1. **LIVE REC (R14).** The model: REC arms the take, starts at the next bar or the first launch, a
   second tap stops it, hold 1.5 s clears it. The code: REC is inert in LIVE (`ui_live.c`), and the
   cheat sheet's "REC tap: undo" and the REC card describe a take that is not recorded yet.
2. **LIVE FX punch effects.** The model: FX held/double-tapped puts six punch FX on the lower keys,
   the upper keys mute roles, HOME+FX resets. The code: FX is inert in LIVE, and there is no
   HOME+FX path anywhere.
3. **LIVE SETUP (EDIT in LIVE).** The model: EDIT opens LIVE SETUP (assign keys, launch default,
   stage lock, external keys channel, Program Change, the take). The code: EDIT is inert in LIVE.
4. **LIVE undo/redo.** The cheat sheet (the task's rows) shows REC undo / PLAY redo in LIVE; the
   code has no LIVE undo/redo (REC is inert, PLAY is the transport and the LIVE in/out).
5. **STUDIO new clip.** The model: REC records a clip from the next bar. The code: SEQ creates the
   clip and opens its settings, but REC only says `REC: T7B` (T7b inserts the editor).
6. **Clearing a knob lane.** The model: "HOME + touch a knob clears that lane"; the cheat sheet (the
   task's row) says K1–K4 touch clears the lane. The code: **SAVE** + a knob forgets its motion
   (`motion_forget`); HOME+PRESETS sets the song tempo; HOME + a knob does nothing.
7. **Reset all FX.** The cheat sheet lists "FX tap = reset all FX" as a HOME combo (the model's
   LIVE performance control). The code has no HOME+FX reset; outside Classic, FX opens its pages,
   and GLOBAL → Factory reset is the nearest thing.
8. **"PAD tap: launch now" in STUDIO.** The model's pad-map rule is "HOME + tap launches
   immediately". In STUDIO a key tap selects and launches at the clip's quantize, and HOME + a held
   pad *clears*; the launch-now combo is implemented in LIVE only. The sheet lists it as the shared
   HOME combo (as the design does), which is exact in LIVE and aspirational in STUDIO.
9. **SCL vs SEL.** The model calls the second panel button SCL; `plat.h` calls it `B_SEL` and the
   panel prints SEL (it toggles the LIVE layers, and in STUDIO launches/clears the cursor clip). The
   cards use the printed label, SEL.
10. **OCT± in STUDIO.** The model lists "OCT± clip banks" as deferred; the code only changes a
    hidden step page (`ui.spage`), with no visible effect. The cards say "no action here yet".

Implemented and matching: HOME+tap pad launches immediately and tap-the-playing-clip stops it
(LIVE); HOME+hold a pad clears with a ring and HOME+REC/PLAY undo/redo (STUDIO); SAVE held opens
SONGS; long PLAY enters/leaves LIVE; holding a pad in LIVE does nothing.
